用 Coze 做一个公众号排版机器人

长李长庆·2026.09.22·7 min

写公众号最烦的不是写，是排版。135 编辑器点来点去半小时，样式还土里土气。上个月我用 Coze 搭了个排版工作流，Markdown 粘贴进去，十秒后拿到带样式的 HTML，直接粘贴进公众号后台。这篇记录搭建思路。

整体思路

公众号编辑器支持粘贴富文本，所以目标很明确：把 Markdown 转成带内联样式的 HTML。内联样式是关键——公众号后台会过滤掉 <style> 标签和 class，只认写在元素 style 属性里的 CSS。

Coze 工作流刚好适合干这个：输入一段文本，走几个节点处理，输出结果，还能直接发布成 Bot 在微信里用。

工作流节点设计

整个工作流四个节点：

  1. 输入节点：接收原始 Markdown 文本
  2. 代码节点：Markdown → HTML 的转换逻辑
  3. 大模型节点：让 AI 根据文章类型微调样式（比如技术文多给代码块留白）
  4. 输出节点：返回最终 HTML

让大模型干粗活

正则转换覆盖不了所有语法，表格和引用块的嵌套处理写正则会让人怀疑人生。我的做法是：简单语法走正则，复杂结构丢给大模型节点。
