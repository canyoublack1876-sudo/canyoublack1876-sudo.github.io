用 FastGPT 搭一个知识库

长李长庆·2026.10.20·8 min

上周帮朋友的公司搭了一个内部知识库：销售想问"这个产品的保修政策是什么"，不用再翻 200 页的 PDF，直接问机器人。用的是 FastGPT，前后花了两天。这篇记录完整的搭建过程和我踩过的坑。

为什么是 FastGPT

市面上的 RAG 工具我试了一圈：Dify 功能全但重，LangChain 自己写太累，Coze 数据出不去。FastGPT 刚好卡在中间——开源、能私有化、工作流可视化，而且向量检索的参数全部可调。

它的核心链路就三步：

  1. 文档切片后向量化，存进 PG Vector
  2. 用户提问时先做语义检索，拿到相关片段
  3. 把片段塞进 prompt，让大模型基于片段回答

召回测试不能省

上线前我写了 50 条测试问题，跑了一遍召回评估：

指标初版调优后
命中率62%87%
平均响应4.2s2.8s

调优只做了两件事：把 embedding 模型换成 bge-large-zh，以及开启混合检索（向量 + 全文）。

最后

FastGPT 不是银弹，但 80% 的内部知识库场景它够用了。下一步我准备写召回评估的具体实现——怎么自动生成测试集。如果你也在搭类似的东西，评论区聊。
