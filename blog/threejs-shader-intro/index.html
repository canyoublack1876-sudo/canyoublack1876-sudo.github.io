Three.js 着色器入门：从第一个 ShaderMaterial 开始

长李长庆·2026.09.06·10 min

最近在做 About 页的 3D 装饰，发现用内置材质怎么调都差点意思。干脆把手伸进了 GLSL，写了一周着色器之后回头看，其实入门门槛没有想象中高。这篇写给和我一样会 Three.js 但没碰过着色器的人。

着色器到底在干嘛

GPU 渲染一个三角形时，会跑两段你写的程序：

  • 顶点着色器（Vertex Shader）：每个顶点跑一次，决定这个顶点最终在屏幕上的位置
  • 片元着色器（Fragment Shader）：每个像素跑一次，决定这个像素是什么颜色

Three.js 的内置材质本质就是官方帮你写好的这两大段程序。ShaderMaterial 则是把这两段程序的编写权交给你。

三个必懂的核心概念

varying 是桥。 顶点着色器里算出的值，通过 varying 传给片元着色器，GPU 会自动在像素间做插值。上面的 vUv 就是经典用法——顶点拿到离散的 uv，片元拿到的是连续插值后的 uv。

uniform 是参数。 从 JS 侧传进去的全局变量，时间、鼠标位置、纹理都走这条路。类型必须严格对应：float 对 number，sampler2D 对 THREE.Texture。

内置变量别混。 position、uv、normal、projectionMatrix、modelViewMatrix 这些在顶点着色器里开箱即用，但片元着色器里没有，想要就得用 varying 自己传。

坑一：GLSL 的浮点数必须带小数点。写 1 不报错但类型是 int，mix(vec3, vec3, int) 直接编译失败，而且报错信息极其不友好。养成写 1.0 的习惯。

调试心得

GLSL 没有 console.log，我的土办法是把中间变量直接输出成颜色：想看 wave 的分布就 gl_FragColor = vec4(vec3(wave), 1.0)，黑白灰度图一目了然。想看 uv 坐标就输出 vec4(vUv, 0.0, 1.0)，红绿渐变告诉你坐标系朝向。

入门资源推荐 The Book of Shaders，有中文版，前六章看完就够用了。
